# WindowIyagi (창이야기)

리눅스 데스크톱에서 **지금 떠 있는 창을 한눈에 보고 다루는** 창 관리 도구입니다.

어느 데스크톱을 쓰든 같은 화면에서 창 목록을 보고, 창을 앞으로 가져오거나 최소화·최대화·복원·닫기를
할 수 있습니다. 터미널 명령도 함께 들어 있어 스크립트에서 창을 다룰 수도 있습니다.

WindowIyagi 는 이야기 시리즈 작업표시줄 **TaskIyagi(작업이야기)** 가 창을 다루는 엔진이기도 합니다.

## ✨ 기능

### 창 목록
* **지금 떠 있는 창 전부** — 창 제목 · 프로그램 · 상태 · 데스크톱(가상 데스크톱 번호, 모든 데스크톱이면 "전체")
* **프로그램 아이콘** 과 함께 표시
* **활성 창 표시** — 지금 쓰는 창은 굵은 글씨와 ● 로 표시
* **실시간 반영** — 창을 열고 닫거나 제목·상태가 바뀌면 바로 목록이 바뀝니다

### 창 제어
* **활성화** — 고른 창을 앞으로 (최소화돼 있으면 되살려서)
* **최소화 · 최대화 · 복원** — 복원은 최소화 → 전체화면 → 최대화 순서로 한 단계씩 되돌립니다
* **닫기** — 프로그램에 정상적인 닫기 요청을 보냅니다. 저장하지 않은 문서가 있으면 프로그램이 물어봅니다
  (강제 종료는 하지 않습니다)
* 데스크톱이 지원하지 않는 동작은 버튼이 흐려지고, 올려 두면 이유가 나옵니다

### 상태 안내
* **노란 띠** — 창 일부만 보이는 환경일 때 그 사실을 알려 줍니다
* **빨간 띠** — 창 목록을 받을 수 없을 때 이유를 알려 줍니다
  (예: GNOME 확장이 꺼져 있음 · 오류로 멈춤 · 확장 관리자의 사용자 확장 스위치가 꺼져 있음)
* 원인이 풀리면 **저절로 다시 연결**합니다

### 이야기 시리즈 창
* 제목바 왼쪽 아이콘 → 정보(버전 · 라이선스), 이름 → 사용법
* 네 변 어디서나 크기 조절, **Shift+드래그** 로 창의 아무 곳이나 잡고 옮기기

## 🖥 지원 데스크톱

실행하면 데스크톱을 스스로 알아보고 알맞은 방식을 고릅니다. 제목바 바로 아래에 지금 쓰는 방식("환경 · 백엔드")이 표시됩니다.

| 데스크톱 | 목록 | 활성화 | 최소화 | 최대화 · 복원 | 닫기 | 준비할 것 |
|---|---|---|---|---|---|---|
| **GNOME** (우분투 · 페도라 기본) | ✅ | ✅ | ✅ | ✅ | ✅ | 처음 한 번 **다시 로그인** (아래 참고) |
| **KDE Plasma** | ✅ | ✅ | ✅ | ✅ | ✅ | 없음 (설치판이 KDE 허락을 함께 설치) |
| **labwc · Wayfire · niri · Hyprland** | ✅ | ✅ | ✅ | ✅ | ✅ | 없음 |
| **sway** (타일링) | ✅ | ✅ | ❌ sway 가 받지 않음 | ❌ sway 가 받지 않음 | ✅ | 없음 |
| **X11 세션** (XFCE · MATE · Cinnamon · LXQt · X11 로 로그인한 GNOME/KDE) | ✅ | ✅ | ✅ | ✅ | ✅ | 없음 |

### GNOME 에서 처음 실행할 때

GNOME 웨일랜드는 보안상 다른 프로그램의 창을 일반 앱에 보여 주지 않습니다. 창을 볼 수 있는 곳은 GNOME 셸
안뿐이라, WindowIyagi 는 처음 실행할 때 창 목록을 전해 주는 작은 **GNOME 확장**을 스스로 설치하고 켭니다.

1. WindowIyagi 를 한 번 실행합니다 — 목록 위에 "확장을 설치했습니다. 다시 로그인하면 켜집니다" 안내가 나옵니다
2. **로그아웃했다가 다시 로그인**합니다 (GNOME 은 새 확장을 로그인할 때만 읽습니다)
3. 다시 실행하면 모든 창이 보입니다

* 확장은 창 목록과 창 제어만 전달합니다. 화면에 따로 그리는 것은 없습니다
* 확장 관리자 **맨 위 "사용자 확장" 스위치를 끄면** 이 확장도 같이 꺼집니다. 다른 확장만 끄려면 그 확장 하나만 끄세요
* 새 버전이 나오면 실행할 때 확장도 알아서 바꿔 끼웁니다(적용은 다음 로그인부터)

## 🎮 사용법

### 창 화면

| 하려는 것 | 방법 |
|---|---|
| 창 앞으로 가져오기 | 목록에서 창을 고르고 **활성화**, 또는 **두 번 클릭** |
| 최소화 · 최대화 · 복원 · 닫기 | 창을 고르고 아래 버튼 |
| 결과 확인 | 아래 상태줄에 "완료" 나 이유가 몇 초 동안 나옵니다 |
| 사용법 · 정보 | 제목바의 이름 · 아이콘 |
| 창 옮기기 | 제목바 끌기, 또는 **Shift+드래그** |

### 터미널 명령

창 목록을 글로 뽑거나, 스크립트에서 창을 다룰 수 있습니다.

```bash
WindowIyagi --list                  # 창 목록 출력
WindowIyagi --activate <창 id>       # 앞으로
WindowIyagi --minimize <창 id>
WindowIyagi --maximize <창 id>
WindowIyagi --restore  <창 id>
WindowIyagi --close    <창 id>
```

`--list` 출력 예:

```
x11:0x1e00007      ----  desk=0   pid=9470    FileIyagi            FileIyagi
595917507          A---  desk=0   pid=10646   org.gnome.Ptyxis     터미널
│                  │     │        │           │                    └ 창 제목
│                  │     │        │           └ 프로그램
│                  │     │        └ 프로세스 번호 (알 수 없으면 0)
│                  │     └ 가상 데스크톱 (0부터, all = 모든 데스크톱, -1 = 알 수 없음)
│                  └ A 활성 · m 최소화 · M 최대화 · F 전체화면
└ 창 id — 다른 명령에 그대로 넘깁니다
```

* 명령은 성공하면 `완료` 를 출력하고 종료 코드 0, 아니면 이유와 함께 1 을 돌려줍니다
* **labwc · sway 등 wlroots 계열**에서는 창 id 가 명령을 실행할 때마다 새로 매겨집니다(`wlr:1`, `wlr:2` …).
  창을 연 순서대로 매겨지므로 대개 같지만, 그 사이 창이 열리고 닫혔다면 `--list` 를 다시 보세요

### 그 밖의 옵션

| 옵션 · 환경변수 | 하는 일 |
|---|---|
| `--install-extension` | GNOME 확장만 설치하고 끝냅니다 (창은 띄우지 않음) |
| `--no-extension-sync` | 실행할 때 GNOME 확장을 확인·갱신하지 않습니다 |
| `WINDOWIYAGI_BACKEND=x11` · `gnome` · `kde` · `wlr` | 자동 감지 대신 방식을 직접 고릅니다 (문제 확인용) |
| `WINDOWIYAGI_DEBUG=1` | 창이 열리고 닫히고 바뀔 때마다 터미널에 기록합니다 |

## 🔗 TaskIyagi 와의 관계

* **TaskIyagi(작업이야기)** 는 WindowIyagi 의 창 엔진을 안에 담고 있습니다. TaskIyagi 만 쓰려면 WindowIyagi 를
  따로 설치할 필요가 없습니다
* GNOME 확장은 둘이 **같은 것 하나**를 함께 씁니다(`windowiyagi@iyagi.com`). 둘 중 먼저 실행한 쪽이 설치합니다
* WindowIyagi 는 작업표시줄이 창을 어떻게 보고 있는지 확인하는 도구로도 쓸 수 있습니다 — TaskIyagi 에 창 버튼이
  안 보이면 WindowIyagi 를 열어 목록과 빨간 띠의 이유를 보면 됩니다

## 🚀 설치

### 우분투 (deb)

```bash
sudo apt install ./windowiyagi_X.X.X~ubuntuXX.XX_amd64.deb
```

* 앱 목록에 **WindowIyagi** 로 나타납니다
* Qt 등 필요한 라이브러리가 함께 들어 있어 따로 설치할 것이 없습니다
* **GNOME** 이면 처음 실행한 뒤 한 번 다시 로그인하세요 ([이유](#gnome-에서-처음-실행할-때))
* **KDE** 에서 창 목록을 허락받는 설정 파일도 함께 설치됩니다

### 지우기

```bash
sudo apt remove windowiyagi
```

GNOME 확장은 사용자 폴더(`~/.local/share/gnome-shell/extensions/windowiyagi@iyagi.com`)에 남습니다.
TaskIyagi 도 쓰지 않는다면 확장 관리자에서 WindowIyagi 확장을 제거하세요.
